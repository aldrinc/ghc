# Metrics

## Leading Metrics
- Number of first-run screens using the new experience shell and components.
- Number of onboarding fields removed, inferred from real sources, or deferred to review.
- Number of real workflow status events surfaced in onboarding.
- Visual QA pass count across desktop and mobile.

## Lagging Metrics
- User can complete workspace setup without reading helper paragraphs.
- User can identify current setup state, next action, and blocked inputs in under 5 seconds.
- Onboarding completion leads to an immediately useful workspace review surface.
- No fake data appears in generated or downstream-consumed artifacts.

## Review Cadence
Review after design-system phase, after onboarding implementation, and after authenticated UI validation.
