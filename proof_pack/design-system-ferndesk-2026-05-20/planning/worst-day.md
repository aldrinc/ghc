# Worst-Day Test

## Scenario
User has no patience, no polished brand assets, only a URL, one product idea, and partial source access.

## The Plan Still Works If
- Every onboarding step has one primary job and one CTA.
- Optional inputs stay skippable without pretending data exists.
- Missing integrations show clean blocked states with direct next actions.
- Setup progress uses real workflow statuses and logs.
- Review screens distinguish generated, missing, blocked, and user-entered material.

## Failure Response
- If product/brand data is missing, block the relevant workflow step with a clean error and visible missing field list.
- Do not create fake proof, categories, competitor data, traffic numbers, or ad counts.
- Do not add fallbacks that silently mask backend failures.
