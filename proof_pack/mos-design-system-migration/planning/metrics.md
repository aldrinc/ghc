# Leading And Lagging Metrics

Leading metrics:

- Core primitives migrated count.
- Raw color/radius/spacing offenders reduced.
- `manus` and borrowed-name references reduced to zero in production source.
- Alias exceptions count, target zero.
- Route surfaces moved to primitives.
- Verification commands passed.
- Brand-sensitive diffs reviewed.

Lagging metrics:

- Product UI reads as one coherent system.
- New screens can use primitives without local one-off styling.
- Internal design-system vocabulary is product-owned or neutral.
- Brand identity remains unchanged.
- Proof pack passes contract verification.
