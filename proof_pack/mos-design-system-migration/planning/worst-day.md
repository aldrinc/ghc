# Worst-Day Test

Bad-day conditions:

- Existing dirty user edits overlap planned files.
- Some screens use old utilities heavily.
- Preview auth state is stale.
- The source HTML has brand examples that are not final.
- Removing borrowed names breaks call sites.

Plan still works if:

- Brand identity blocks stay untouched.
- Token and primitive layers compile.
- Borrowed names are refactored rather than permanently aliased.
- Main product routes render without broken layout.
- Blocked routes are listed with exact causes.
- No fake fallback styling or fake data is introduced.
