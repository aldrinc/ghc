# Designed Machine

1. UI asks workspace name and new vs existing.
2. Existing branch asks business website URL and optional competitors, then Context.dev extracts setup context with provenance.
3. Existing branch shows "Does this look right to you?" with editable extracted fields before workspace creation.
4. New branch asks business model, "What do you sell or plan to sell?", and product/service-specific setup questions.
5. Frontend submits marketing-agent setup payload through a "Create workspace" CTA.
6. Backend creates workspace/offering shell only from user input or source-grounded extraction.
7. Backend creates pricing/variant data only when price or rate is known and applicable.
8. Backend supports new and existing business stages.
9. Background workflow prepares competitor landscape, buyer context, and avatar docs internally.
10. Workflow persists foundation bundle as agent memory.
11. Workspace moves to "Marketing agent ready".
12. Product/service-specific offer, proof, voice, channels, claims constraints, design system, and copy are collected later.
