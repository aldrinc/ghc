# Problem Log

Top problems:

1. Current onboarding starts full Strategy V2, so later-stage offer/copy requirements leak into first-run UX.
2. Existing business selection is exposed but backend rejects it.
3. Price is required because onboarding creates a non-null priced variant.
4. UI asks too many fields before giving value.
5. Downstream prerequisites currently treat offer/copy completion as part of onboarding readiness.
6. Existing and new businesses are not separated enough: existing businesses should use website extraction, while new businesses need direct product/service questions.
7. Product and service pricing are not distinct enough: products ask for price, services ask how the service is charged.
8. Existing-business scraping needs a defined provider and prompt/data-point contract, otherwise extraction quality will drift.
9. Customer review must be editable because source-grounded Context.dev data can still be wrong or incomplete.
