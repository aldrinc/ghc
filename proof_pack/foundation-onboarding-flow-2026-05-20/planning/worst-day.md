# Worst-Day Test

A tired customer can still finish whether the business already exists or is only an idea.

Existing-business minimum:

1. workspace name
2. existing business
3. business website URL
4. skip optional competitors
5. review "Does this look right to you?"
6. edit wrong extracted fields if needed
7. create workspace

New-business minimum:

1. workspace name
2. new business
3. business model
4. product or service
5. offering name
6. offering description
7. skip optional pricing
8. skip optional competitors
9. create workspace

Pass condition: the marketing agent can be set up without fake price, fake proof, fake URLs, or fake copy context. Existing-business extracted fields need Context.dev-backed source evidence or stay unknown. Internal foundation docs can run in the background.
