# Current Machine

Current mOS machine:

- Strategy, creative, copy, funnels, Meta specs, and publish runs already live in mOS.
- Meta services can use stored encrypted tokens to call Meta APIs.
- Post-publish management can fetch ad-level insights and create deterministic recommendations.
- Hermes can run against projected runtime bundles.
- Social posting has a separate Postiz scope doc, but is not yet unified with Meta account connectivity.

Weakness:

- The system can perform pieces of the workflow, but it does not yet expose a clean customer connection -> provider asset grant -> snapshot -> agent proposal -> approval -> execution loop.
