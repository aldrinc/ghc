# Goal

Create a reviewable PRD for a first-party mOS connected social agent platform that covers:

- Meta Ads Manager Agent: connect customer Meta ad accounts, pull real ad data, diagnose performance, and execute approved actions.
- Social Media Manager Agent: connect customer Meta social assets, draft posts, schedule or publish approved posts, and pull performance data.

The PRD is complete when it is specific enough to turn into an implementation plan without re-deciding the control-plane architecture.
