# Metrics

Leading metrics:

- successful OAuth connections by workspace
- connected provider assets with healthy sync state
- read-only sync success/failure rate
- agent runs with source-backed proposals
- proposal approval rate
- provider write failure rate

Lagging metrics:

- time from connection to first useful ads diagnosis
- time from draft request to approved social post
- percent of external writes with complete action ledger records
- repeat workspace usage
- reduction in manual Meta tool switching

No numeric targets are set in the PRD because no baseline has been measured yet.
