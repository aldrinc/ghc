# Metrics

Leading metrics:

- connected publishing channels
- connected conversion sources
- approved content variants
- successful Postiz submissions
- successful analytics syncs
- conversion events with source provenance
- reports with non-empty source-backed recommendations

Lagging metrics:

- time from program setup to first approved carousel
- time from publication to first synced social metric
- percent of publications with matched release ids
- percent of conversion events with concrete attribution
- repeat experiment creation by workspace

No numeric targets are set because baseline usage data does not exist yet.
