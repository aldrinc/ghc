# Designed Machine

Designed mOS machine:

1. User creates a content growth program for an app/product.
2. User connects publishing channels through Postiz.
3. User connects one conversion source through a generic adapter.
4. Hermes researches and proposes content experiments.
5. mOS renders TikTok carousel variants and stores slide assets.
6. User approves final rendered payload.
7. mOS submits approved payload to Postiz.
8. mOS syncs publication state and social analytics.
9. mOS syncs conversion events.
10. mOS attributes conversions with explicit confidence labels.
11. Hermes generates the next experiment plan from source-backed data.
